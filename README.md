Anime Quiz Challenge

An interactive multiple-choice trivia quiz built with vanilla JavaScript, pulling from a pool of 47 anime-themed questions and presenting a random 10-question run each time it's played.

Features
A pool of 47 trivia questions covering popular anime and manga (Naruto, One Piece, Attack on Titan, Death Note, Bleach, My Hero Academia, Demon Slayer, and more)
Each playthrough randomly selects 10 questions from the pool, so no two runs are guaranteed to be identical
Multiple-choice format with 4 answer options (radio buttons) per question
Progress indicator showing the current question number out of the total
Running score tracked across the quiz
